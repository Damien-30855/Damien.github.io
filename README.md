# PNRU Sport: ระบบยืม-คืนอุปกรณ์กีฬา

เว็บแอปพลิเคชันสำหรับยืม-คืนอุปกรณ์กีฬา มหาวิทยาลัยราชภัฏพระนคร
พัฒนาด้วย Python + Flask + MySQL (XAMPP) ออกแบบตามหลักการเขียนโปรแกรมเชิงวัตถุ (OOP)

ผู้จัดทำ: พงษ์สิทธิ์ มูฮำหมัดรอโซน (6810122115028) · ภควัตร พงษ์สว่าง (6810122115057) · ภัทร กาทอง (6810122115054) · พิชิตชัย เสนคะ (6810122115002)

## สิ่งที่ต้องมี

- Python 3
- XAMPP (ใช้ MySQL/MariaDB ที่มากับ XAMPP)

## วิธีติดตั้งและรัน

1. เปิด **XAMPP Control Panel** → กด **Start** ที่ **MySQL**
   (กด Start ที่ Apache ด้วยถ้าจะดูข้อมูลผ่าน phpMyAdmin ที่ http://localhost/phpmyadmin)
2. เปิด Terminal ในโฟลเดอร์นี้ แล้วติดตั้งไลบรารี
   ```
   pip install -r requirements.txt
   ```
3. สร้างฐานข้อมูล (ข้อมูลเดิมในฐานข้อมูล `pnru_sport` จะถูกลบทั้งหมด)
   ```
   python init_db.py --demo
   ```
   - `--demo` = มีข้อมูลตัวอย่าง (นักศึกษา 3 คน, รายการยืมครบทุกสถานะ, จำนวนอุปกรณ์ตัวอย่าง)
   - ไม่ใส่ `--demo` = เริ่มระบบจริง มีแค่อุปกรณ์ 8 ชนิด (จำนวน 0) และบัญชีแอดมิน
   - **อีกวิธี (ไม่ต้องรันคำสั่ง):** เปิด http://localhost/phpmyadmin (ต้อง Start Apache ด้วย) → แท็บ **Import** → เลือกไฟล์ `pnru_sport_demo.sql` → กด **Import**
     ได้ข้อมูลเหมือนรัน `python init_db.py --demo` ทุกอย่าง
4. รันเว็บ
   ```
   python app.py
   ```
5. เปิดเบราว์เซอร์ไปที่ **http://127.0.0.1:5000**

ถ้าหน้าเว็บขึ้นว่า "เชื่อมต่อฐานข้อมูลไม่ได้" แปลว่ายังไม่ได้กด Start ที่ MySQL ใน XAMPP

## เปิดจากโทรศัพท์ (Wi-Fi วงเดียวกัน)

1. ให้คอมพิวเตอร์ที่รัน `python app.py` กับโทรศัพท์ต่อ **Wi-Fi วงเดียวกัน**
2. หา IP ของคอมพิวเตอร์: เปิด Command Prompt พิมพ์
   ```
   ipconfig
   ```
   ดูบรรทัด **IPv4 Address** ใต้หัวข้อ Wireless LAN adapter Wi-Fi เช่น `192.168.1.35`
   (หรือดูใน Terminal ตอนรัน `python app.py` จะมีบรรทัด `Running on http://192.168.x.x:5000` ให้ด้วย)
3. เปิดเบราว์เซอร์ในโทรศัพท์ไปที่ **http://<IP>:5000** เช่น http://192.168.1.35:5000

ถ้าโทรศัพท์เปิดไม่ได้
- ครั้งแรกที่รัน `python app.py` Windows จะถามเรื่อง Firewall ให้กด **Allow access**
  (ถ้าเผลอกดปิดไป: Windows Security → Firewall & network protection → Allow an app through firewall → ติ๊ก Python)
- ตั้งเครือข่าย Wi-Fi ในคอมพิวเตอร์เป็น **Private** (Settings → Network & internet → Wi-Fi → ชื่อ Wi-Fi → Network profile type)
- Wi-Fi บางที่ (เช่น Wi-Fi มหาวิทยาลัย) กันไม่ให้อุปกรณ์มองเห็นกัน ให้ใช้ Hotspot จากโทรศัพท์แทน แล้วให้คอมพิวเตอร์ต่อ Hotspot นั้น

ทุกเครื่องใน Wi-Fi วงเดียวกันเปิดเว็บนี้ได้ จึงควรใช้ Wi-Fi ที่ไว้ใจได้

## ความปลอดภัย (ตั้งใน `config.py`)

- `DEBUG = False` (ค่าเริ่มต้น) = โหมดใช้งานจริง/พรีเซนต์ ถ้าเว็บ error จะแสดงข้อความภาษาไทย ไม่โชว์โค้ด · **แก้โค้ดหรือ `config.py` แล้วต้องกด Ctrl+C แล้วรัน `python app.py` ใหม่เอง**
- `DEBUG = True` = โหมดพัฒนา แก้โค้ดแล้วเว็บรีสตาร์ทเอง ใช้ตอนเขียนโค้ดบนเครื่องตัวเองเท่านั้น
- `SECRET_KEY = ""` (ค่าเริ่มต้น) = ระบบสุ่มกุญแจ session ใหม่ทุกครั้งที่เปิดเว็บ ไม่มีใครรู้ค่าจึงปลอมตัวเป็นแอดมินไม่ได้ · ผลข้างเคียง: รีสตาร์ทเว็บแล้วทุกคนต้อง login ใหม่

## บัญชีทดสอบ

| บทบาท | ชื่อผู้ใช้ | รหัสผ่าน | ชื่อ |
|---|---|---|---|
| แอดมิน | `admin1` | `admin1234` | สมชาย ใจดี |
| แอดมิน | `admin2` | `admin1234` | อารีย์ สุขสม |
| นักศึกษา | `6512345678901` | `123456` | ธนกฤต อินทร์แก้ว |
| นักศึกษา | `6512345678902` | `123456` | พิมพ์ชนก ศรีสุข |
| นักศึกษา | `6512345678903` | `123456` | วีรภัทร มั่นคง |

- หน้าเข้าสู่ระบบมีช่องเดียว ป้ายเขียนว่า "รหัสนักศึกษา" แต่แอดมินพิมพ์ username (เช่น `admin1`) ในช่องเดียวกันได้
- บัญชีนักศึกษามีเฉพาะเมื่อรัน `init_db.py --demo` (หรือสมัครใหม่ผ่านหน้า "สมัครสมาชิก")
- ระบบไม่มีหน้าสมัครแอดมิน บัญชีแอดมินสร้างใน `init_db.py` (แก้ได้ที่ `ADMIN_LIST`)
- นักศึกษาลืมรหัสผ่าน: แอดมินเปิดเมนู "ค้นหาสมาชิก" → "ดูประวัติ" → ปุ่ม "รีเซ็ตรหัสผ่าน" แล้วตั้งรหัสใหม่ให้ (ไม่มีการส่งอีเมล)

## ทดสอบนอกเวลาทำการ (เวลาจำลอง)

ระบบรับจองเฉพาะจันทร์-ศุกร์ 09:00-15:30 ถ้าจะทดสอบนอกเวลานี้ ให้แก้ `FAKE_NOW` ใน `config.py`

```python
FAKE_NOW = "2026-09-28 10:00:00"    # ปี-เดือน-วัน ชั่วโมง:นาที:วินาที
FAKE_NOW = None                     # กลับไปใช้เวลาจริง
```

บันทึกไฟล์ แล้ว**หยุดเว็บด้วย Ctrl+C และรัน `python app.py` ใหม่** (เพราะ `DEBUG = False` เว็บจะไม่โหลดค่าใหม่เอง) แล้ว login ใหม่
ระหว่างใช้เวลาจำลอง หน้าเว็บจะมีแถบสีเหลือง "โหมดทดสอบ: เวลาจำลอง …"

ข้อมูลตัวอย่างเป็นรายการวันที่ 20-22 ก.ย. 2569 ถ้าอยากเห็นหน้าเว็บตรงกับหน้าต้นแบบ ให้ตั้ง
`FAKE_NOW = "2026-09-22 10:17:00"` แล้วรัน `python init_db.py --demo` ใหม่
(หน้า "ยืมอุปกรณ์" ของ `6512345678901` จะเห็นการ์ดการจอง "รอยืนยัน" · `6512345678902` เห็นการ์ดกำลังยืม · `6512345678903` เห็นการ์ดเกินกำหนด)
(ถ้าใช้เวลาจริง ระบบจะเปลี่ยนสถานะรายการเก่าให้อัตโนมัติ: "รอยืนยัน" → "ยกเลิก", "กำลังยืม" → "เกินกำหนด")

## โครงสร้างไฟล์

```
pnru-sport/
├── app.py              หน้าเว็บทั้งหมด (Flask routes)
├── models.py           คลาส Student, Admin, Equipment, BorrowRecord และกติกาของระบบ
├── database.py         คลาส Database เชื่อมต่อ MySQL และอ่าน/บันทึกข้อมูล
├── schema.sql          คำสั่งสร้างฐานข้อมูลและตาราง (ยังไม่มีข้อมูล)
├── init_db.py          สร้างฐานข้อมูลใหม่ + ข้อมูลเริ่มต้น
├── pnru_sport_demo.sql ฐานข้อมูลพร้อมข้อมูลตัวอย่าง สำหรับ Import ผ่าน phpMyAdmin
├── config.py           ค่าเชื่อมต่อฐานข้อมูล และเวลาจำลอง
├── test_models.py      ทดสอบคลาส
├── TESTING.md          รายการทดสอบระบบแบบกดเอง (ให้ทีมกรอกผล)
├── requirements.txt    ไลบรารีที่ต้องติดตั้ง
├── templates/          หน้าเว็บ (HTML + Jinja2)
├── static/style.css    รูปแบบหน้าเว็บ (ยกมาจาก prototype รวมแบบมือถือ)
└── static/favicon.svg  ไอคอนแท็บตัว S
```

## ตั้งค่าฐานข้อมูล

ค่าเริ่มต้นใน `config.py` ตรงกับ XAMPP แล้ว (host `localhost`, พอร์ต `3306`, ผู้ใช้ `root`, ไม่มีรหัสผ่าน, ฐานข้อมูล `pnru_sport`)
ถ้าตั้งรหัสผ่าน MySQL ไว้ ให้แก้ `DB_PASSWORD` ใน `config.py`
